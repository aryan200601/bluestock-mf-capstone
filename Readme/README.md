# 📊 Mutual Fund Analytics Platform

## Bluestock Fintech Capstone Project

An end-to-end Mutual Fund Analytics Platform developed using Python, SQLite, and Power BI to analyze mutual fund performance, investor behavior, industry trends, and portfolio risk. The project integrates ETL pipelines, advanced analytics, risk assessment, and interactive dashboards to generate actionable investment insights.

---

## 🚀 Project Objectives

* Build a complete ETL pipeline for mutual fund datasets.
* Perform Exploratory Data Analysis (EDA).
* Calculate fund performance metrics.
* Implement advanced risk analytics.
* Analyze investor behavior and SIP trends.
* Develop a rule-based fund recommendation engine.
* Create interactive Power BI dashboards.
* Generate business insights and recommendations.
